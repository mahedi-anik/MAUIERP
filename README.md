\# MAUI ERP System



A production-ready Enterprise Resource Planning (ERP) system built with .NET 9 MAUI Blazor Hybrid, following Clean Architecture and DDD principles.



\## 🚀 Features



\- \*\*Multi-Platform Support\*\*: Windows, macOS, iOS, Android

\- \*\*Modern UI\*\*: MudBlazor components with Material Design

\- \*\*Company \& Branch Management\*\*: Full CRUD operations with GUID IDs

\- \*\*JWT Authentication\*\*: Secure token-based authentication

\- \*\*Role-Based Access Control\*\*: Granular permissions system

\- \*\*User Management\*\*: Complete user administration

\- \*\*Audit Logging\*\*: Track all data changes

\- \*\*Real-time Updates\*\*: SignalR integration ready



\## 🏗️ Architecture



\- \*\*Clean Architecture\*\* with separation of concerns

\- \*\*Domain-Driven Design\*\* principles

\- \*\*CQRS\*\* with MediatR

\- \*\*Repository Pattern\*\* with Entity Framework Core

\- \*\*Specification Pattern\*\* for queries



\## 🛠️ Technology Stack



\- \*\*.NET 9\*\* - Latest .NET framework

\- \*\*MAUI Blazor Hybrid\*\* - Cross-platform UI

\- \*\*Entity Framework Core\*\* - ORM

\- \*\*MudBlazor\*\* - Material Design components

\- \*\*MediatR\*\* - Mediator pattern implementation

\- \*\*AutoMapper\*\* - Object mapping

\- \*\*FluentValidation\*\* - Input validation

\- \*\*Serilog\*\* - Structured logging

\- \*\*JWT\*\* - Authentication



\## 📋 Prerequisites



\- .NET 9 SDK

\- Visual Studio 2022 (17.8+) or VS Code

\- SQL Server (LocalDB, Express, or higher)
